 Overview

A command-line Student Grade Management System built in Python. It stores student records (name, grades per subject, attendance) in memory during runtime and persists them to a CSV file so data isn't lost between sessions.

 Features Implemented

- Add new student with grade validation (0–100) and duplicate name check
- View all students in a formatted table
- Class report: total students, class average, highest/lowest average, pass/fail count, rankings sorted by average
- Individual student report card with rank, grade letter, and attendance
- Save/load data to and from `students.csv`

 Bonus Features Implemented

- Grade letter (A/B/C/D/E/F) calculated from average
- Subject-wise class average in the class report
- Individual report card exportable as a `.txt` file
- Attendance tracking per student (mark daily present/absent, view attendance %)
- Custom subjects — new subjects can be added at runtime; existing students are prompted for a grade in the new subject so data stays consistent

 How to Run
 Run this in a terminal (or IDLE), not in a plain output panel — the program uses `input()` and needs an interactive console.
